## Projets

### Projet 1 (Java):Application de gestions de motos
Objectif du projet:  
Ce projet a été réalisé pour pratiquer la programmation orientée objet en Java ainsi que la structuration d’une application en plusieurs couches (modèle, service, interface).  
Fonctionnalités  
L’application permet de :  
      - Ajouter une moto  
      - Afficher la liste des motos  
      - Supprimer une moto  
      - Rechercher une moto  
Toutes les interactions se font via un menu dans la console.  

Technologies utilisées  
      - Java  
      - Programmation orientée objet  
      - Architecture simple (Model / Service / Main)  
      - Structure du projet  

Moto : classe représentant une moto (marque, modèle, année, kilométrage, prix)  
MotoService : logique de gestion des motos  
Main : interface console et menu utilisateur  
Objectif pédagogique  
Ce projet fait partie de mon apprentissage en développement logiciel. Il m’a permis de comprendre :  
      - la gestion d’objets en Java  
      - la séparation entre logique métier et interface  
      - la création d’une application console interactive  

Évolution du projet  
Une future version du projet pourrait inclure :  
      - une interface graphique avec JavaFX  
      - la sauvegarde des données dans un fichier ou une base de données  

### Projet 2 (C): Gestion de Machines Virtuelles (VMS)  
     Ce projet implémente un système de gestion de machines virtuelles capable d’exécuter des programmes LC‑3.
Il met en pratique des concepts clés des systèmes d’exploitation :  
      - Gestion mémoire en C  
      - Manipulation sécurisée des pointeurs  
      - Exécution d’instructions machine  
      - Architecture client‑serveur  
      - Débogage avancé  
      
Description du problème    

Lors des premières exécutions, plusieurs erreurs critiques ont été observées :  
      - Segmentation fault lors de l’accès mémoire    
      - Opcode LC‑3 non reconnu (« OP inconnu »)  
      - Comportements imprévisibles lors de transactions  
      - Instabilité générale du système  
Ces problèmes empêchaient l’exécution correcte des fichiers de transactions.  

Objectifs pédagogiques  

Ce TP permet de maîtriser :  
      - la gestion mémoire en C  
      - la manipulation sécurisée des pointeurs  
      - la conception d’un mini‑interpréteur LC‑3  
      - la communication client‑serveur   
      - le débogage d’un système complexe    
      
Améliorations possibles  

- interface graphique pour visualiser les VM  
- logs avancés  
- gestion multi‑clients  
- persistance des VM sur disque  
- interpréteur LC‑3 plus complet
