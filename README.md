###  Gestion de machines virtuelles (C)

Implémentation d’un système capable d’exécuter des programmes LC-3, simulant un environnement de machine virtuelle.

####  Fonctionnalités
- Exécution d’instructions LC-3
- Gestion mémoire
- Simulation d’un système bas niveau

####  Technologies
- Langage C
- Gestion mémoire (malloc/free)
- Manipulation de pointeurs
- Architecture client-serveur

####  Compétences développées
- Programmation bas niveau
- Débogage avancé (segmentation fault, erreurs mémoire)
- Compréhension des systèmes et architectures

####  Améliorations possibles
- Interface de visualisation des VM
- Gestion multi-clients
- Logs détaillés
- Persistance des données
